# Quality Suites — Sprint 1-3 Production-Readiness Tests

These suites complement the unit + integration tests under `tests/test_*/`.
They answer questions a typical PR pipeline cannot: **are the tests
catching real bugs (mutation testing), does the system survive 24h of
load (soak), how does the agent behave under adversarial input, and is
the supply chain trustworthy?**

| Suite | Trigger | SLO | Where |
|---|---|---|---|
| **Mutation** | Nightly (04:00 UTC) + manual | Score ≥ 80 % on TRUST modules | [`cosmic-ray.toml`](../../cosmic-ray.toml) + [`tests/quality/`](../../tests/quality) |
| **Adversarial** | Per-PR + nightly | 0 attacks bypass Gatekeeper RED | [`tests/adversarial/`](../../tests/adversarial) |
| **Soak** | Weekly (Sun 02:00 UTC) | 24h: 0 leak, 0 lock storm, audit head intact | [`tests/soak/`](../../tests/soak) |
| **SBOM** | Per-release tag | Signed CycloneDX + 0 known CVEs | [`.github/workflows/quality-sbom.yml`](../../.github/workflows/quality-sbom.yml) |
| **Chaos** | Nightly | All PGE-loop fault primitives recover | [`tests/chaos/`](../../tests/chaos) |
| **Migration round-trip** | Per-PR (touched migrations only) + nightly full | Lossless forward+backward | [`tests/migrations/`](../../tests/migrations) |
| **Architecture fitness** | Per-PR | 0 contract violations | [`.importlinter`](../../.importlinter) + [`tests/architecture/`](../../tests/architecture) |
| **AI output regression** | Nightly | LLM-judge drift < 10 % | [`tests/ai_regression/`](../../tests/ai_regression) |
| **SLO p95/p99** | Per-PR | < 15 % regression on hot paths | [`tests/slo/`](../../tests/slo) |
| **Playwright journeys** | Per-PR (preview) + nightly (full) | All happy paths green | [`flutter_app/integration_test/journeys/`](../../flutter_app/integration_test/journeys) |
| **a11y** | Per-PR | WCAG 2.1 AA on Chat / Settings / Dashboard | [`flutter_app/integration_test/a11y/`](../../flutter_app/integration_test/a11y) |
| **External pentest** | Annual + before major release | Findings tracked in private GHSA | [`docs/security/pentest-brief.md`](../security/pentest-brief.md) |

## How to run locally

```bash
# Install quality extras (heavyweight — only when needed)
pip install -e ".[dev,quality]"

# Mutation testing on a small subset (~5 min)
cosmic-ray init cosmic-ray.toml session.sqlite \
    --paths src/cognithor/video/routing.py
cosmic-ray exec cosmic-ray.toml session.sqlite
python tests/quality/score_mutations.py session.sqlite

# Adversarial corpus (~30 sec)
pytest tests/adversarial/ -q

# Architecture fitness
lint-imports

# SLO regression
pytest tests/slo/ --benchmark-only --benchmark-compare-fail=median:15%

# Soak — 1h dry-run (24h needs dedicated machine)
locust -f tests/soak/locustfile.py --headless -u 10 -r 2 -t 1h

# AI output regression (needs LLM judge — Anthropic API key)
ANTHROPIC_API_KEY=... pytest tests/ai_regression/ -q
```

## CI cadence

| Cadence | Suites |
|---|---|
| **Per-PR (must-green)** | Adversarial · Architecture fitness · SLO · Migration round-trip (touched) · a11y |
| **Nightly (03:00 UTC)** | Burn-in + Chaos + AI regression + Migration full + Mutation |
| **Weekly (Sun 02:00 UTC)** | 24h soak |
| **Per-release tag** | SBOM + signed wheel + pip-audit |
| **Annual** | External pentest |
